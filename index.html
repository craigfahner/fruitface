To replace your webcam's image with this fruit-filtered version...

  • Download OBS, an open source video streaming and capture program
  • open this fruitface filter in its own browser window
  • open OBS, click on settings. navigate to the "video" tab. set both the Base and Output resolution to 1280x960.
  • in OBS, create a new window capture, selecting the browser window that contains the fruitface filter
  • move the image in the preview canvas so that the video image fills the canvas completely
  • click on "Start Virtual Camera". This will create a virtual camera device on your computer
  • select "OBS Virtual Camera" as your webcam in Zoom/Teams/whatever you like
